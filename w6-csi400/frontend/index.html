💡 สรุปประโยชน์ของ Automate Testing (ตามสไลด์)

1. ลดเวลาในการทดสอบ (Time Saving)

ไม่ต้องเสียเวลากดคลิกทดสอบทีละเส้นด้วยมือ เปลี่ยนเป็นการรันอัตโนมัติ 24 เคสเสร็จสิ้นใน 0.4 วินาที

2. ป้องกันข้อผิดพลาดซ้ำ (Regression Prevention)

เวลาแก้โค้ดหรือเพิ่ม Feature ใหม่ มั่นใจได้ว่าโค้ดส่วนอื่นจะไม่พัง หากมีจุดเสียหาย Test จะฟ้องทันที

3. เชื่อมต่อ CI/CD ได้สะดวก (CI Ready)

นำคำสั่ง npm test หรือ Newman ไปรันตรวจคุณภาพก่อน Deploy ขึ้นเซิร์ฟเวอร์จริงได้อัตโนมัติ

4. ค้นหาข้อบกพร่องได้เร็ว (Early Bug Detection)

ตรวจพบจุดผิดพลาดตั้งแต่ขั้นตอนเขียนโค้ด ลดต้นทุนและเวลาในการแก้บักในภายหลัง

📜 ตัวอย่างการเขียน Script ใน Postman (ตามสไลด์หน้า 2-3)

// 1. ตรวจสอบ HTTP Status 200 (pm.test)
pm.test("Status is 200 OK", function () {
    pm.response.to.have.status(200);
});

// 2. ตรวจสอบ Content-Type เป็น JSON
pm.test("Response is JSON", function () {
    pm.response.to.have.header("Content-Type");
    pm.expect(pm.response.headers.get("Content-Type")).to.include("application/json");
});

// 3. เก็บ Token ใส่ Environment อัตโนมัติ (Dynamic Auth)
const json = pm.response.json();
if (json.token) {
    pm.environment.set("authToken", json.token);
}
